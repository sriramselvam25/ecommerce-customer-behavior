# Insights & Recommendations

This project uses synthetic data; insights become reproducible after running the deterministic generator and loading the model.

## Decision framework
- **Protect:** monitor high-value / loyal segments for declining order frequency or margin.
- **Grow:** identify high-AOV segments and channels with healthy margin and below-target penetration.
- **Recover:** prioritize at-risk customers with historically strong value.
- **Optimize:** investigate categories where revenue grows but margin or target attainment weakens.

## Executive questions
1. Which customer segments contribute disproportionate revenue and margin?
2. Which channels acquire value versus merely volume?
3. Where does YoY growth fail to translate into profitability?
4. Which combinations of segment, channel and category should receive retention investment?
